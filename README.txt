KHMER JUMP - home-screen version
================================
Upload everything in this folder (keep the files together, same folder) to any web host that serves HTTPS:
  - GitHub Pages: make a repo, upload these files, Settings > Pages > deploy from the main branch.
  - Netlify / Cloudflare Pages: drag and drop the folder.
Then open the web address on your phone:
  - iPhone (Safari): Share > Add to Home Screen.
  - Android (Chrome): menu > Install app / Add to Home screen.
The Lava Jump emblem is the icon, and the game opens full screen, landscape.
It also works offline after the first visit.

Notes
- Levels, words and progress are saved on the phone itself (not in an account), so they stay across visits but not across devices.
- "Add English with Claude" only works inside claude.ai; elsewhere type the English as: water = ទឹក
